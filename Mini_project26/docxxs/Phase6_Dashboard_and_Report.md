# Phase 6 — Dashboard & Report

**Status:** ⬜ Not started

## Goal
Present the result so it's obvious and submission-ready.

## Plan
1. React + Recharts frontend: pick a company → show its signal, predicted direction, and
   overlay the actual price path.
2. Surface the three headline numbers: classifier accuracy (Phase 3), drift predictability
   (Phase 4), strategy Sharpe/return (Phase 5).
3. Written report: methodology, results, limitations, market-efficiency interpretation.
4. Optional slides / recorded demo.

## The three numbers that define success
1. **Classifier accuracy / AUC** — can language predict the firm's true type?
2. **Drift predictability** — does the signal forecast returns the market missed?
3. **Backtest Sharpe** — does acting on it make money after costs?
